# Smoosher 1.1.0

This tester prerelease adds a refreshed interface, visible metering, smoother control changes, and better preset recall while retaining Smoosher's existing compression curves and plugin identifiers.

## What's new

- Gain-reduction and stereo output meters, peak hold, and a click-to-clear clip indicator.
- Larger interface with rounded editable value boxes, a compact rotary Mix control, and a Hammer-mode indicator.
- 20 ms smoothing for parameter changes; the processing curves at settled settings are retained.
- User preset saving, preset names saved with sessions, and a modified indicator. Presets continue to leave Mix unchanged.
- Nine new factory presets: Mr. Cetera, Dockside Divorce, Drum Bus, Bass in Boat Shoes, Snare Custody Battle, Oops! All Room Mics, Live, Laugh, Limit, Divorced Dad Clean Tone, and Hard Dick™.
- Signed, notarized universal Mac installer and automated Mac/Windows build checks.

## Downloads

- **macOS:** `Smoosher-1.1.0-macOS-universal.pkg` installs AU and VST3 for Apple Silicon and Intel. Requires macOS 11 or later and administrator authorization. The installer is Developer ID signed, notarized, and stapled.
- **Windows:** `Smoosher-1.1.0-Windows.zip` contains the unsigned x64 VST3 bundle. Extract and copy the entire `VST3/Smoosher.vst3` bundle to `C:\Program Files\Common Files\VST3\`.
- **Checksums:** `SHA256SUMS.txt` covers both downloads.

Close your DAW before installing. If upgrading from a manual Mac install, move old per-user Smoosher copies out of `~/Library/Audio/Plug-Ins/Components/` and `~/Library/Audio/Plug-Ins/VST3/` to avoid duplicate versions, then rescan in your DAW. Existing parameter and plugin IDs are preserved for session compatibility.

## Testing feedback

Please try AU/VST3 scanning, playback, automation, preset saving, and reopening existing sessions. Adjust Input for your source and Output to level-match; the heavy presets are also useful blended with Mix. The output trim can still push peaks above 0 dBFS.

Report issues at https://github.com/seamoss/smoosher/issues with your OS, DAW/version, plugin format, and reproduction steps. Wider DAW and minimum-OS coverage is the purpose of this prerelease; Windows binaries are not code-signed.
